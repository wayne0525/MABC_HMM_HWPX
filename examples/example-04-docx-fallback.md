# 예제 4 — HWPX를 저장하지 못할 때

Timely 문서 생성기가 `.hwpx`를 못 주면 실패한 척 침묵하지 말고 폴백 계약을 지킨다.

## 출력

1. 요약표 — 단위 있는 A 값 (XML에서 왔든 추정이든 상태 열에 표시)
2. 누락 — `결과 파일을 DOCX로 저장함. 한글에서 HWPX로 다시 저장하면 됨.`
3. `C_주간실적_서식이식.docx`
4. 재적용 메모:

```
한글에서 열기 → 다른 이름으로 저장 → HWPX
전체 선택 후:
- 글꼴 함초롬바탕, 본문 13pt
- 줄간격 160%
- 여백 위 20mm 아래 15mm 좌우 30mm
- 표 테두리 0.12mm, 헤더 배경 #D9E1F2
```

DOCX 본문 글꼴이 함초롬이 아니면 그 사실을 누락에 적는다. 사용자에게 “HWPX와 동일”이라고 하지 않는다.
