# 예제 3 — 표가 많은 초안

## 상황

B에 표 4개, 병합 셀 있음. A는 헤더 행이 남색(#1F4E79) 흰 글자, 선 0.2mm.

## 지킬 것

- 각 표의 행×열, 병합, 셀 문자열은 B
- 모든 표의 선 0.2mm, 헤더 남색, 헤더 글자 흰 색은 A tableHeader
- 숫자 `3.0%`와 `3%`를 통일하지 않음
- 빈 셀 유지

## 열 너비

B 표가 A4 가로에 맞춰져 있고 A는 세로면, 열 비율만 유지하고 전체 폭을 A 본문 폭에 맞춘다. 오른쪽이 잘리면 실패.

## 잘못된 처리

- 표를 탭으로 구분된 문단으로 풀어 씀
- 헤더 배경을 B의 회색으로 유지
- 병합을 풀고 값을 반복 입력

## 이미지 표 (스캔)

셀을 OCR로 새로 치면 숫자가 틀린다. 읽기 신뢰가 낮으면 표를 이미지로 옮기고 누락에 `표 2는 스캔이라 셀 텍스트를 재입력하지 않음` 을 적는다. 틀린 숫자를 넣는 것보다 낫다.
