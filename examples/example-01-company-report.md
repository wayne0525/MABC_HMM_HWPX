# 예제 1 — 회사 양식 A + 초안 B

Solar가 흉내 낼 정답 패턴. 숫자를 이 예제에서 다른 파일로 복사하지 말 것. **방법**만 복사.

## 사용자

첨부: `사내보고서_양식.hwpx`, `주간실적_초안.hwpx`  
말: 첫 파일이 양식, 둘째가 내용이야. 합쳐줘.

## A에서 측정된 값 (예시)

XML을 연 결과라고 가정.

- 용지 A4 세로, 여백 20/15/30/30 mm
- body: 함초롬바탕 / Latin Times New Roman / 13pt / #000000 / 양쪽 / 줄간격 160%
- heading1: 함초롬돋움 16pt 굵게 #000000 / 왼쪽 / 문단 아래 6pt
- heading2: 함초롬돋움 13pt 굵게
- heading3: 없음
- tableHeader: 함초롬돋움 12pt 굵게, 배경 #D9E1F2, 선 0.12mm #000000
- tableBody: 함초롬바탕 12pt, 배경 없음, 같은 선
- documentTitle: 함초롬돋움 18pt 굵게 가운데

A 표지 문장 “○○주식회사 주간 업무 보고서” 는 **저장하지 않음**.

## B 골격 (예시)

1. title: `8월 3주차 주간 실적`
2. heading1: `1. 이번 주 완료`
3. paragraph: `API 지연을 12% 줄였다.`
4. heading1: `2. 수치`
5. table 2×3: 헤더 `항목|목표|실적` / 행 `응답시간|200ms|176ms`
6. heading2: `2.1 남은 일`
7. listItem: `- 배포 창구 문서화`

B는 맑은 고딕 11pt, 줄간격 130%, 왼쪽 정렬 — **전부 버림**.

## 매핑

- title → documentTitle
- heading1 → heading1
- heading2 → heading2
- paragraph → body
- listItem → list (A list 없으면 body, 마커 `-` 유지)
- table 첫행 → tableHeader, 나머지 tableBody

## C에서 맞아야 하는 것

- 첫 줄 텍스트: `8월 3주차 주간 실적` (A의 주식회사 문구 없음)
- 본문 글꼴 함초롬바탕 13pt 양쪽 160%
- 표 셀 `176ms` 그대로
- 선 0.12mm, 헤더 배경 #D9E1F2

## 사용자에게 보이는 요약 (축약)

| 항목 | A에서 가져온 값 | C에 적용 |
|------|-----------------|----------|
| 한글 글꼴 | 함초롬바탕 | 예 |
| 본문 크기 | 13pt | 예 |
| 줄간격 | 160% | 예 |
| 선 굵기 | 0.12mm | 예 |
| 여백 | 위 20 / 아래 15 / 좌우 30 mm | 예 |

누락: heading3 없음(해당 없음). 이미지 없음.

파일: `C_주간실적_서식이식.hwpx`
