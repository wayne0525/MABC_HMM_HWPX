# 예제 2 — A에 제목 단계가 부족한 경우

## 상황

A 양식은 제목1·본문만 있다 (간단한 메모 양식).
B는 `1.` `1.1` `1.1.1` 세 단계 보고서.

## 잘못된 처리 (하지 말 것)

- B의 1.1.1을 위해 맑은 고딕 20pt 새 스타일을 만듦
- 모든 제목을 16pt로 같게 만들어 계층이 사라짐
- B의 큰 글자 크기를 그대로 써서 A가 무너짐

## 올바른 처리

roleMap:

```
heading1 → heading1
heading2 → heading1 (fallback, A에 heading2 없음) + 본문 앞 “1.1” 텍스트는 B에 이미 있으므로 유지
heading3 → heading1 (fallback) 
```

더 나은 변형: heading2/3은 **body+bold** 슬롯이 있으면 그쪽으로 떨어뜨려 제목1과 차별. A에 bold 본문이 없으면 heading1 남용보다 body+bold가 낫다. 제목1을 세 수준에 반복하면 목차가 평평해 보여도 A 글꼴은 지킨다.

사용자 누락:

```
- A에 제목2·제목3 서식이 없어 하위 제목은 본문 굵게로 떨어뜨림. 번호 문자열(1.1.1)은 초안 그대로임.
```

창작 금지: 임의의 14pt, 임의의 남색.
