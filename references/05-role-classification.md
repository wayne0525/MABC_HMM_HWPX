# 역할 분류 — 제목인지 본문인지

이식은 **역할 → A 슬롯**이다. B의 포인트 크기를 역할로 쓰지 마라.

## 우선순위 (위에서 아래로 첫 일치)

1. **XML heading**  
   `paraPr`의 `heading @level` ≥ 1, 또는 style 이름이 `개요 1`/`제목 1`/`Heading 1`.
2. **번호 개요**  
   문단 전체가 `1.` `1.1` `가.` `Ⅰ.` 로 시작하고 한 줄이 짧음 → heading. 점 개수·자릿수로 level.
3. **문서 제목**  
   본문 시작 쪽, 가운데 정렬이거나 단독 짧은 줄, 다음에 저자/날짜/본문이 옴 → `documentTitle`. **A 표지의 기관명과 비교하지 말 것.**
4. **캡션**  
   `표 1`, `표1.`, `그림 2`, `<표>` 로 시작 → `caption`.
5. **목록**  
   글머리 `•` `-` `·` `①` 또는 numbering id → `list`.
6. **인용**  
   왼쪽 여백이 본문보다 크고 짧은 블록. 불확실하면 `paragraph`.
7. **표 헤더**  
   표의 첫 행이 짧고 모든 열이 명사형(“구분/내용/비고”) → `tableHeader`. 아니면 첫 행도 `tableBody`.
8. **나머지** → `paragraph` / body.

애매하면 **본문**이다. 제목으로 올리면 A의 큰 글꼴이 본문 한 줄에 붙어 양식이 망가진다.

## 한국어 문서에서 자주 나오는 패턴

| 보이는 것 | 역할 |
|-----------|------|
| `1. 추진 배경` | heading1 |
| `1.1 국내 동향` | heading2 |
| `가. 개요` | heading2 또는 heading1 (문서 관례). 상위 `1.`이 있으면 heading2 |
| `□ 주요 내용` | list 또는 heading3. 다음이 긴 문장이면 heading3 |
| `o 첫째,` ` - ` | list |
| `붙임 1.` `별첨` | heading1 |
| 날짜 `2026. 8. 29.` 한 줄 | paragraph (제목 아님) |
| `수신자`, `제목:` 기안문 필드 | paragraph. 양식 칸이면 표일 수도 |

## A 쪽 슬롯을 고를 때

A에서 같은 휴리스틱을 써 **슬롯을 채운다.** 다만 A의 실제 문장은 저장하지 않고 ID/서식만.

A에 heading3 스타일이 전혀 없으면 `present: false`. B의 heading3는 heading2로 떨어뜨린다 (`06-mapping-and-id-remap.md`).

## 부분 굵게

본문 문단 중 일부 런만 굵다 → 역할은 그대로 body. `emphasis` 런이다. 문단 전체를 heading으로 승격하지 마라.

## 잘못된 분류 예

- B 표지가 22pt라서 모든 22pt를 제목1로 처리 → 본문 인용문까지 제목이 됨.
- A의 머리글 “내부용”을 documentTitle로 처리 → C 첫 줄이 양식 문구가 됨.
- 표 안 굵은 첫 셀을 heading1로 처리 → 표가 깨짐. 표 안은 tableHeader/tableBody만.
