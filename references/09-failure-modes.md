# Solar Pro 4 실패 모드 — 제출 전에 이 목록을 훑는다

각 항목은 실제 모델이 HWPX/문서 이식에서 반복하는 실수다. 해당하면 C를 다시 만든다.

## 내용 오염

| 증상 | 원인 | 수정 |
|------|------|------|
| C 첫 줄이 A 회사명/양식 제목 | A 텍스트를 템플릿으로 착각 | A 문장 전부 제거, B 제목부터 |
| 문장이 더 매끈해짐 | 윤문 | B 원문 복구 |
| 표 숫자가 반올림됨 | “정리” | B 셀 문자열 복구 |
| 영어 본문이 한글로 번역됨 | 과잉 도움 | B 언어 유지 |
| 빈 칸에 ‘해당 없음’을 채움 | 빈 셀을 오류로 봄 | 빈 문자열 유지 |

## 서식 오염

| 증상 | 원인 | 수정 |
|------|------|------|
| 본문이 B 글꼴 | B 헤더를 merge | A 헤더만, ID 재지정 |
| 줄간격 이상하게 넓음 | 160을 160pt로 해석 | `02-units.md` |
| 글자가 거대함 | height 1200을 1200pt | /100 |
| 여백이 거의 없음/과함 | HWPUNIT을 mm로 착각 | /283.5 |
| 표 선이 너무 굵음 | 0.12를 12pt | mm |
| 제목만 A이고 본문은 기본 맑은 고딕 | body 슬롯을 안 채움 | 최빈 본문 ID |
| 양쪽 정렬이 왼쪽이 됨 | 기본값 | A align |
| 컬러 제목이 검정만 됨 | 강조색 무시 | A heading textColor |

## ID

| 증상 | 원인 | 수정 |
|------|------|------|
| 한컴이 파일을 거부 | 헤더에 없는 IDRef | A에 있는 ID만 |
| 본문이 제목 글꼴 | B id 2를 A id 2로 해석 | 역할 맵으로 재지정 |
| itemCnt 불일치 | 스타일 추가 후 카운트 미갱신 | 자식 수와 일치 |

## 패키지

| 증상 | 원인 | 수정 |
|------|------|------|
| 열리지 않음 | mimetype 압축/위치 | 첫 엔트리 STORED |
| 그림 X박스 | 3-way 불일치 | BinData+hpf+section |
| 편집 후 줄이 겹침 | linesegarray 잔존 | 삭제 |
| `.hwp`를 억지 처리 | 바이너리 | 변환 요청 후 중단 |

## 구조

| 증상 | 원인 | 수정 |
|------|------|------|
| 표 열 사라짐 | 표를 문단으로 풀어 씀 | table 블록 유지 |
| 제목 수준이 전부 1 | pt로 분류 | `05-role-classification.md` |
| 목록 번호가 1부터 다시 시작하지 않음 | numbering ID를 B 것 사용 | A list 슬롯, 텍스트 번호는 B 문자열 유지 |
| 페이지가 B 가로, A 세로 | pagePr를 B에서 복사 | A pagePr |

## 폴백

HWPX를 못 만들면 실패가 아니다. DOCX/PDF + 재적용 표를 내고 이유를 한 줄로 적으면 계약 충족이다.
조용히 확장자만 바꾸는 것은 실패(사용자가 한글로 못 염).

## 자가 질문 (예/아니오)

답이 하나라도 아니오/모르쇠면 사용자에게 파일을 주기 전에 고친다.

1. C에서 A의 고유 문장이 검색되는가? → 아니어야 함
2. C 본문 글꼴 이름이 A 본문과 같은가?
3. 줄간격에 %가 붙어 있는가?
4. 표 셀 원문이 B와 같은가?
5. 추정 숫자에 “추정”이 붙었는가?
