# B에서 뽑을 내용 카탈로그

B의 **보기(서식)는 전부 버린다.** 아래만 가져온다. 스키마: `schemas/content-skeleton.schema.json`.

순서를 바꾸지 않는다. 문장을 고치지 않는다. 오탈자도 그대로.

## 블록 타입

문서 전체를 위에서 아래로 `blocks[]`로 만든다.

| type | 가져올 것 | 버리지 말 것 |
|------|-----------|--------------|
| `title` | 텍스트 | 문서 맨 위 큰 제목으로 **구조상** 보이는 것 |
| `heading` | 텍스트, level 1~3 | 번호(`1.`, `가.`)가 내용의 일부면 텍스트에 포함 |
| `paragraph` | 런 단위 텍스트 | 굵게/기울임 **여부만** 표시(내용은 B, 색/글꼴은 나중에 A) |
| `listItem` | 기호 문자, 깊이, 텍스트 | `1)` 같은 번호 문자열 |
| `table` | 행×열, 각 셀 텍스트, 병합 | 빈 셀은 `""` |
| `image` | 위치, 파일명/id, 대체 텍스트 | BinData를 옮길 수 있으면 옮김 |
| `caption` | 텍스트 | `표 1`, `그림 2` |
| `footnote` | 본문 위치 + 주석 텍스트 | |
| `pageBreak` | 의미 있는 쪽 나눔만 | 빈 쪽 맞추기용 연속 나눔은 생략 가능 |
| `quote` | 텍스트 | |
| `equation` | 원문 또는 “수식 있음” | 재구성 실패 시 `unsupported` |
| `textbox` | 텍스트 | 실패 시 누락 |
| `headerText` / `footerText` | B에 있는 문자열만 | A 머리글을 넣지 않음 |

## 문단 안 런 (부분 강조)

```
paragraph: {
  runs: [
    { text: "매출은 ", bold: false },
    { text: "12.3%", bold: true },
    { text: " 증가했다.", bold: false }
  ]
}
```

`bold`/`italic`/`underline` 플래그는 **의미 강조**라서 유지한다.
글자색·글꼴·크기는 저장하지 않는다. C에서는 A의 `emphasis` 또는 본문+bold 슬롯을 쓴다.

색만 다르고 굵지 않은 강조는 `emphasis: true`로만 표시하고, C에서 A의 강조색이 있으면 그것을 쓴다. A에 강조색이 없으면 본문색+굵게.

## 제목 수준을 서식으로 판단하지 말 것

B의 글자가 22pt여도, A에 제목1이 16pt면 C는 16pt다.
수준은 **구조**로만:

- 개요 번호 `1.` `1.1` `1.1.1`
- `hp:heading @level`
- 단독 짧은 줄 + 다음이 본문
- 목차 스타일 이름(B 헤더의 style name) — 이름은 힌트, 숫자는 힌트가 아님

자세한 규칙은 `05-role-classification.md`.

## 표

```
table: {
  rows: 3,
  cols: 2,
  cells: [
    { r:0, c:0, rowspan:1, colspan:1, text: "구분" },
    { r:0, c:1, rowspan:1, colspan:1, text: "금액" }
  ]
}
```

- 셀 안 여러 문단은 `\n`으로 잇는다.
- 숫자·단위·공백 보존 (`1,000 원`을 `1000원`으로 바꾸지 않음).
- 셀 배경·선은 저장하지 않는다 (A의 표 스타일이 덮음).
- 열 너비: B의 열 비율을 유지하는 것이 내용 가독성에 필요하면 `colWidthsRel[]`만 상대값으로 저장. 절대 HWPUNIT은 B 용지 기준이라 A 여백과 충돌할 수 있다. 상대 비율이 안전하다.

## 이미지

세 곳 동기화 (`01-hwpx-package.md`).
못 옮기면 블록을 `unsupported: "image"`로 두고 누락 목록에 파일명/설명을 적는다. 가짜 사각형을 그리지 않는다.

## 버리면 안 되는 공백·줄바꿈

- 문단 구분(Enter)은 블록 경계.
- Shift+Enter(`lineBreak`)는 같은 문단 안 줄바꿈으로 보존.
- 장식용 빈 문단이 3개 연속이면 1개로 줄여도 된다. 0개로 지우면 구역이 붙으니 1개는 남긴다.

## 버리면 되는 것 (B)

- 모든 charPr/paraPr 숫자
- B의 용지·여백
- B의 테마 색
- `linesegarray`
- 미리보기 PNG
- 작성자 메타 (필요 없으면)
