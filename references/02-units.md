# 단위 — 틀리면 문서가 우스워진다

한글 내부 숫자는 사람 단위가 아니다. Solar는 **저장값 → 사람 단위**로 바꿔 사용자 표에 쓰고, C를 만들 때만 다시 저장값으로 돌린다.

## 세 단위

| 이름 | 쓰이는 곳 | 관계 |
|------|-----------|------|
| **HWPUNIT** | 용지, 여백, 셀 크기, 들여쓰기, (글자 height도 이 스케일) | 1 inch = 7200 HWPUNIT |
| **pt** | 사람이 말하는 글자 크기, 문단 위아래 간격 | 1 pt = 100 HWPUNIT |
| **%** | 줄간격 `lineSpacing type="PERCENT"` | value 160 = 160% (160pt가 아님) |
| **mm** | 사람이 말하는 여백·용지·선굵기 | 1 mm ≈ 283.465 HWPUNIT |

선 굵기는 XML에 `0.12mm` 같은 문자열로 오기도 하고 HWPUNIT으로 오기도 한다. 사용자에게는 **mm**로 통일한다.

## 글자 크기

`hh:charPr @height` (또는 동일 의미의 글자 높이):

```
pt = height / 100
```

| height | pt |
|--------|----|
| 900 | 9 |
| 1000 | 10 |
| 1100 | 11 |
| 1200 | 12 |
| 1300 | 13 |
| 1400 | 14 |
| 1600 | 16 |
| 1800 | 18 |
| 2000 | 20 |
| 2200 | 22 |
| 2400 | 24 |
| 2800 | 28 |
| 3600 | 36 |

**금지:** height 1000을 1000pt, 10mm, 100%로 읽기.

## 줄간격 (line gap)

```xml
<hh:lineSpacing type="PERCENT" value="160"/>
```

| type | value 의미 | 사용자에게 |
|------|------------|------------|
| `PERCENT` | 글자 크기 대비 % | `160%` |
| `FIXED` | 고정 줄 높이 (보통 HWPUNIT 또는 pt 스케일) | `고정 18pt`처럼 단위를 밝혀 씀 |
| `AT_LEAST` | 최소 줄 높이 | `최소 18pt` |
| `LINE` | 배수 | 값 해석이 불명확하면 `unknown` |

한국 공문·보고서는 **160%**, **180%**, **200%** 가 흔하다. 130%는 답답하고 250%는 느슨하다. A 값을 바꾸지 마라.

**금지:** 160을 160pt, 1.6cm, 16pt로 쓰기.

## 자간·장평

```xml
<hh:spacing hangul="0" latin="0"/>   <!-- 자간. 0이 기본. +면 넓어짐 -->
<hh:ratio hangul="100" latin="100"/> <!-- 장평. 100 = 100% -->
<hh:relSz hangul="100" .../>
```

사용자에게: 자간 `0`, 장평 `100%`. A가 0이 아니면 그대로 옮긴다.

## 문단 간격·들여쓰기

- 문단 위/아래 (`before` / `after`): 보통 pt 또는 HWPUNIT. 100 HWPUNIT = 1pt.
- 왼쪽/오른쪽 여백, 첫줄 들여쓰기: HWPUNIT → mm.
- 음수 indent는 내어쓰기(번호 목록).

```
mm ≈ HWPUNIT / 283.465
```

## 용지·페이지 여백

A4 세로: width `59528` × height `84186` HWPUNIT (210 × 297 mm).
A4 가로: 값이 바뀐다.

자주 나오는 여백:

| HWPUNIT | mm (반올림) |
|---------|-------------|
| 2835 | 10 |
| 4252 | 15 |
| 5669 | 20 |
| 7087 | 25 |
| 8504 | 30 |
| 11339 | 40 |

기본 한글 여백 예: 위 20mm / 아래 15mm / 좌우 30mm → top 5668, bottom 4252, left/right 8504.

머리글/바닥글 영역 `header`/`footer`도 HWPUNIT이다. **내용 문자열이 아니라 간격**이다.

## 선 굵기 (line width)

표·문단 테두리 `borderFill`의 `width`. 한글 UI 이름과 대응:

| 한글에서 흔히 | 대략 |
|---------------|------|
| 0.1mm / 가는 선 | 0.10 mm |
| 0.12mm | 0.12 mm |
| 0.2mm | 0.20 mm |
| 0.4mm | 0.40 mm |
| 0.5mm | 0.50 mm |
| 1.0mm 굵은 선 | 1.00 mm |

**금지:** 0.12를 12pt, 12mm로 쓰기. 선 굵기는 글자 크기가 아니다.

## 색

`textColor`, 테두리 `color`, 셀 채움: `#RRGGBB`.
`shadeColor="none"` 은 배경 없음.
한글 자동은 종종 `#000000`. A가 `#222222`이면 C도 그 값.

## 변환 체크

사용자 표에는 항상 단위를 붙인다.

- 글꼴 크기: `13pt`
- 줄간격: `160%`
- 여백: `위 20mm / 아래 15mm / 좌 30mm / 우 30mm`
- 선: `0.12mm` 실선 `#000000`
- 색: `#000000`

내부 JSON에는 `raw` (XML 숫자)와 `display` (사람 단위)를 같이 두는 것이 좋다.
