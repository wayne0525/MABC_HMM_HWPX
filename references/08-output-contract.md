# 사용자에게 보이는 출력 계약

내부 JSON은 숨긴다. 사용자 답은 항상 이 세 덩어리, 이 순서.

## ① 이식 요약표

짧을 것. 단위 필수.

| 항목 | A에서 가져온 값 | C에 적용 |
|------|-----------------|----------|
| 한글 글꼴 | 예: 함초롬바탕 | 예 / 부분 / 아니오 |
| 영문 글꼴 | | |
| 본문 크기 | 13pt | |
| 본문 색 | #000000 | |
| 제목1 크기·굵기 | 16pt 굵게 | |
| 줄간격 | 160% | |
| 문단 정렬 | 양쪽 | |
| 선 굵기 | 0.12mm 실선 | |
| 표 헤더 배경 | #F2F2F2 | |
| 용지 | A4 세로 | |
| 여백 | 위 20 / 아래 15 / 좌우 30 mm | |

적용 열: `예` = 측정값 사용. `추정` = visual-estimate. `불가` = 누락 참고.

## ② 주의/누락

불릿, 최대 8개.

반드시 넣을 것:

- 읽지 못한 서식 (줄간격을 XML에서 못 봄 등)
- 옮기지 못한 내용 (이미지, 수식, 글상자)
- fallback (heading3→heading2, HWPX→DOCX)
- `usedEngineDefaultBorder` 같은 기본값 사용

없으면 “없음” 한 줄.

## ③ 파일 C

- 파일명: `C_{주제또는원본명}_서식이식.hwpx`
- 미리보기 텍스트를 보여 줄 때 **첫 3문단은 B의 문장**이어야 한다. A 문장이 보이면 실패이므로 파일을 지우거나 다시 만든다.
- HWPX 불가 시: `C_....docx` 또는 PDF + 아래 재적용 수치 표.

### 폴백 재적용 표 (한글에서 손볼 때)

문서 생성 도구가 HWPX를 못 만들 때만 붙인다.

```
한글 열기 → 전체선택 →
글꼴 [이름] 크기 [N]pt
줄간격 [N]%
여백 [..]
표: 테두리 [N]mm 색 [#] 헤더 배경 [#]
```

한 줄 이유: `Timely 문서 생성이 HWPX를 지원하지 않아 DOCX로 저장함.`

## 톤

- 한국어, 평서문, 짧음.
- 이모지 금지.
- “완벽하게 복제” 금지.
- 채널/모델 이름(Solar)을 자랑하지 말 것.

## 질문할 때

A/B가 불명이면 한 줄:

`어느 파일이 서식(A)이고 어느 파일이 내용(B)인가요? 예: 첫 파일이 회사 양식, 둘째가 초안`

그 외의 설문(선호 글꼴 등)은 하지 않는다. 선호는 A가 정한다.
