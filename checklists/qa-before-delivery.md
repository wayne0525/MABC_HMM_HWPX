# 파일 C를 주기 전

`09-failure-modes.md`와 함께 쓴다.

- [ ] C 본문에 A 고유 문장(회사 표지, 양식 안내문)이 없다
- [ ] C 본문 글자열이 B와 같다 (윤문 없음). 대략 글자 수 10% 이상 감소 없음
- [ ] 본문 글꼴 이름 = A 본문
- [ ] 본문 크기 pt = A (height/100)
- [ ] 줄간격에 % 또는 “고정 Npt”가 있고, 160을 160pt로 쓰지 않았다
- [ ] 여백이 mm이고 HWPUNIT 생값을 그대로 쓰지 않았다
- [ ] 선 굵기가 mm이다
- [ ] 표 행·열·셀 텍스트가 B와 같다
- [ ] heading 폴백을 누락에 적었다
- [ ] 못 옮긴 이미지/수식을 누락에 적었다
- [ ] 추정값에 “추정”이라고 썼다
- [ ] 사용자 답이 요약표 → 누락 → 파일 순서다
- [ ] 미리보기 첫 문단이 B의 제목/본문이다
- [ ] HWPX가 아니면 폴백 이유 한 줄 + 재적용 표
