# team/ui.md

## 담당

- 클라이언트(공개 페이지, 요청/응답 처리, 사용자 노출 요약) 담당: 담당자 3

## 현재 상태(준비 커밋 기준)

- 공개 페이지: `vercel/public/index.html`
- 현재 요청 경로(페이지 코드): `/api/transplant`
- 현재 요청 필드명(페이지 코드): `style`, `content`
- 현재 응답 처리: blob 다운로드 + `X-Transplant-Summary` 헤더 기반 요약 표
- 사용자 노출 요약은 이식 요약표/누락/파일 순서(계약서·출력 계약 참조)

## 정리할 불일치

- 페이지가 호출하는 경로와 필드명을 서버 계약(`/api/fill`, `a`, `b`)과 맞춘다
- 응답이 바이너리인지 JSON인지에 따라 다운로드/요약 표시 방식을 맞춘다
- 상세 계약은 `docs/TEAM_CONTRACT.md` 참조

## 진행 규칙

- UI는 서버 계약을 따르는 방향으로만 수정
- 빈 구현 stub 요청은 UI 쪽에서도 만들지 않음
